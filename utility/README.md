# Utilities

Optional tools that work alongside md-reader. Each one is deployed separately from the reader's website and has its own guide.

| Tool | What it does |
|---|---|
| [vtt-aligner](vtt-aligner/) | Makes read-along timing files (`.vtt`) from a chapter's narration audio and its Markdown, via a small upload page or an HTTP API. Self-hosted; nothing leaves your server. |

The reader's web server configuration blocks this folder, so none of it is reachable from the reader's site.
